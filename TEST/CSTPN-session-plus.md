# CSTPN-session-plus

会话列表增强：置顶、行内重命名、会话内搜索。

## 功能

### 置顶会话

右键菜单「置顶会话」/「取消置顶」：

- 记录存 localStorage，跨重启保留
- 置顶行加旗标并移到分组最前（今天/一周/一月/更早 各组内置顶优先）

### 行内重命名

右键「重命名」或**双击会话行**，直接在列表里改名（替代原生 window.prompt 弹框）：

- Enter 确认，Esc 取消，失焦视为确认
- 提交走 `PATCH /api/sessions/<id>`，成功后立即更新显示

### 会话内搜索

`Ctrl / Cmd + F` 拉起搜索条（编辑器内不抢占）：

| 交互 | 行为 |
| --- | --- |
| 输入 | 220ms 防抖后高亮全部命中 |
| Enter / ↓ | 下一个 |
| Shift+Enter / ↑ | 上一个 |
| Esc / × | 关闭并清理高亮 |

高亮用文本节点替换实现，关闭时完整还原原文。
