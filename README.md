**CST Pilot** 是计算机维护队（Computer Service Team，**CST**）的便携式专用 Agent，为队员提供现场维修时的 AI 技术支持。
**CSTP Next** 是对CST Pilot进行便捷化修改的脚本集，不修改原安全政策，仅添加使用优化。
