# CSTPN-session-plus

会话列表增强。

## 功能

**置顶会话** — 右键「置顶会话」/「取消置顶」：

- 记录存 localStorage，跨重启保留
- 置顶行加旗标并移到分组最前

**行内重命名** — 右键「重命名」或双击会话行，在列表里直接改名：

- Enter 确认，Esc 取消，失焦视为确认
- 提交走 `PATCH /api/sessions/<id>`

**会话内搜索** — 进入会话后，页头**三点菜单左侧**出现搜索按钮：

| 交互 | 行为 |
| --- | --- |
| 点击搜索按钮 | 拉起搜索条 |
| 输入 | 防抖后高亮全部命中 |
| Enter / ↓ | 下一个 |
| Shift+Enter / ↑ | 上一个 |
| Esc / × | 关闭并清理高亮 |

同时会在 **设置 → 快捷键 → 聊天操作** 末尾追加一行说明。
